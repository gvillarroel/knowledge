# Isolated EnterpriseRAG evolution runner

This package provides the frozen public decision policy, exact native request
broker, source-bound candidate and task versioning, isolated process launcher,
and one-way finalization lifecycle. Harbor remains the owner of scoring,
qualification, provenance, Pareto archives and native reports.

Start with the [execution guide](../../docs/enterprise-isolated-evolution.md)
and [architecture decision](../../.specs/adr/0165-isolate-the-frozen-enterprise-evolution-planner.md).
Preparation and synthetic rehearsal do not authorize a native study. Fresh
independent validation registration, review and seal remain required.

All generated datasets, candidate packages, traces and native evidence belong
under ignored repository-local working directories. Publish reviewed aggregate
reports only; preserve existing sealed E14 and E15 evidence unchanged.
