## Useful generator behavior

JSON/CSV schemas with fields beyond identity/title now require an explicit
`fields` object before construction. Partial maps remain authoritative and
`fields: {}` deliberately selects title-only knowledge. An absent decision
produces an actionable error and no expert output. Native Markdown and RDF source
semantics remain intact.

New experts contain a digest-bound `references/source-coverage.json` with
declared, mapped and omitted fields; explicit selection status; normalized record,
non-null/null mapped value and body-character counts; and native/derived scope.
It explicitly reports `raw_source_fidelity_verified: false`. Raw-to-ledger fidelity
and embedding context coverage still require their separate checks.

## Validation history and implementation checks

G1's private native jobs aborted during artifact collection before any verifier
started. Its scores remain unavailable and its consumed cohort was never retried.
G2 preserves the exact candidate bytes and uses a fresh prospectively sealed
cohort. The supported explicit artifact-copy route passed dummy separate-container
byte checks and a two-task native public preflight with all four artifact entries
`ok`. No shared Harbor code was modified; the underlying intermittent filesystem
cause remains unproven. G2 used one fixed 16-trial development comparison and one
16-trial private gate, plus the separate two-trial technical preflight.

The promoted canonical generator passed **18 tests with zero warnings**.
The application gate passed **1,395 tests at
90.7% total coverage**, above the required
80%. The application was checked separately because its coverage scope excludes
the standalone generator suite. Transport/catalog tests, dataset descriptors,
report regeneration, local links and ignored-data hygiene were also verified.

These are descriptive construction results from a small technical pilot. Curator
confidentiality relies on a shared-host role and tool-read boundary. There is no
population-confidence, autonomous model-use, EnterpriseRAG retrieval-ranking or
generated-answer-quality claim.

Sources, cases, generated experts, frozen candidates, private review and native
jobs remain ignored. Public reports contain reviewed aggregates and commitments.
Local completed native reports are under `tmp/g2/native-reports/`; the original G1
interruption is preserved under its own study and report paths.
