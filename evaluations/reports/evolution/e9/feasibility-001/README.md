# Fixed Graphify builder feasibility on EnterpriseRAG

The exact reviewed Graphify builder **qualified** in its sole E9 native attempt. This result governs whether that package may become the reference for a separately sealed consultation study.

The trial uses 120 already exposed questions, 112 with references, and 6,000 reference-enriched complete documents. Category weights total 470. It is one deterministic retrieval task, with no language-model answer scoring.

| Weighted nDCG@10 | Recall@10 | MRR@10 | Full evidence@10 |
| ---: | ---: | ---: | ---: |
| 8.12% | 14.85% | 6.71% | 12.53% |

Both complete builds produced byte-identical output. Native package, task, submission and runtime checks passed, with evidence integrity 1 and no execution error. The reporter's 0.8 reward threshold is a diagnostic label; the prospectively fixed feasibility gate requires finite scores and exact integrity, without a quality cutoff.

The [original E8 builder attempt](../../e8/graphify-baseline-failure-001/README.md) exceeded its first-build limit and has no retrieval score. Therefore E9 supplies neither a measured quality gain over that original nor a native speed ratio. The [synthetic scaling result](../../e8/graphify-scaling-001/README.md) remains separate evidence.
