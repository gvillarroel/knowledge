# Construction evaluation: native-owner path portability and preserved results

The two construction candidates still have no new EnterpriseRAG measurement.
The latest ordinary evaluation passed its complete startup control in
**363.287 seconds**, then both worker controls failed before native attempt
creation. The dispatcher completed with exit 1 and the maintained organizer
recorded the diagnostic evidence and stopped the study. The
[source-bound aggregate](aggregate.json) preserves the outcome and accounting.

Later reproduction identified a Windows/Linux compatibility defect: the
Windows control used its own filesystem path semantics to validate a Linux
process executable. The same persisted dispatch failed on Windows and passed
under the actual Linux runtime. The original refusals contain only a generic
metadata error; this specific cause comes from the later reproduction.

An isolated two-line correction uses explicit POSIX syntax for that native
path. It passed **76 Windows checks and 95 Linux checks**, including the
complete persisted dispatch, synthetic attempt and terminal receipts for both
families, and rejection of changed types, identities, caps and retry fields.
All other source text reverses exactly to the parent. The correction retains
the original Linux policy and the separate process-provenance checks. These
are metadata tests, not a successful workload or current execution admission.
