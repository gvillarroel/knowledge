## Cost, time and scope

This run completed **12 Python commands**: four builds, four independent
validations and four queries. Its one container ran for **89.84 seconds**
with two CPU cores, a 6 GiB limit, no network and a read-only root filesystem.
Eight exact mounts were inspected; an empty read-only mount masked the image's
baked benchmark input. The narrow model cache and all package/input/control
bytes remained unchanged. The container exited successfully, was not OOM-killed
and was removed with no cleanup errors.

There were zero Harbor trials, benchmark questions, language-generation calls,
automatic retries or additional proposal charges. Learned embedding inference
did run; its internal call count and host-compute cost are unknown. Peak memory
was not measured. Small-fixture completion within 6 GiB does not establish that
the 6,000-document build will fit.

The initial atomic harness failure remains failed: its global cleanup patch
intercepted parent setup before candidate execution. The corrected atomic
harness used module-local proxies and workspace temporary paths. The initial
runtime fixture was rejected during review and never executed; V2 corrected
six isolation, source-binding and failure-preservation issues before this one
permitted run. Neither preparation outcome is a semantic-quality measurement.

The construction proposal remains a single nonrefundable claim: 82 total claims
at this checkpoint, with 104 remaining in Ensemble's existing allowance. No
native allocation or canonical skill installation is implied. The next native
stage still needs the exact full-corpus workload, prospective controls and
separate Entity Graph feasibility. Final family search, all-500 comparison and
independent acceptance remain required.
