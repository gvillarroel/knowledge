traversal and fusion scores and ranks, plus resolved entities and supporting

The generic planner's conditional expensive-signal operator is therefore not

6.575 cumulative query seconds (66.13%)** to graph traversal across 48 queries.
Those times include profiler overhead. They describe the preserved synthetic
workload, not the phase that caused the native EnterpriseRAG timeout.

Source inspection finds two conversions of each immutable numeric edge weight
and repeated calculation of the same hop power inside the edge loop. A bounded
arithmetic experiment compared **8,400 scalar combinations**. Converting that
weight once and reusing the same hop power, while retaining multiplication
order, preserved every tested IEEE-754 result exactly.

changed the floating-point result in **753 combinations**. That shortcut cannot
be presented as exact arithmetic preservation. For example, the experiment's
first differing pair is recorded as hexadecimal floats in the [aggregate](aggregate.json).
This is synthetic numeric evidence, not benchmark question or answer data.
