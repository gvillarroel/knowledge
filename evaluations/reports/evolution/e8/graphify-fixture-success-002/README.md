# Graphify: complete public artifact parity passed

The fixed second public host fixture design passed all required checks. The
unchanged sealed builder candidate and original constructor generated identical
complete packages within each layout. Across layouts, graph bytes and logical
query semantics remained equal after independently checking each physical
snapshot and citation location.

| Required scope | Completed result |
| --- | --- |
| Synthetic fixtures | Four, with 1, 6, 8 and 12 records |
| Physical layouts | Record per file and source packed |
| Paired layout cells | 8 of 8 |
| Original/candidate arm cells | 16 of 16 |
| Ordinary independent constructions | 32 |
| Additional deterministic check rebuilds | 16 |
| Read/inspection/validation/query commands | 330 |
| Negative-validator decisions | All 16 rejected their declared corruption |
| Top-level command outcomes | All 394 matched their declared exit code |
| Host elapsed time | 301.75 seconds |
| Harbor trials and model calls | 0 |

The fixtures cover a singleton, unrestricted ties, partition boundaries and
heterogeneous text. Every arm/layout cell used two independent complete builds,
a check rebuild, original and candidate family validators, the standalone expert
validator, deep verification, inspection, native and enriched queries, physical
evidence hydration and unchanged complete package checks. A separate all-candidate
mutual-neighbor oracle checked graph endpoints exactly; its independently summed
scores used the prospectively declared absolute tolerance of 1e-12. Paired
implementation payload equality had no tolerance or same-layout exclusions.

The negative cases checked semantic graph corruption, missing record projection,
altered source evidence and undeclared content. The sixteen expected validator
exit codes were 2; all other commands exited zero. These decisions are preserved
with their exact mutations and diagnostics in the ignored execution artifact.

Before cross-layout comparison, the runner independently reconstructed every
native physical snapshot hash and checked it in expert validation, deep
verification, inspection and both query payload forms. It rechecked the snapshot
after consultation. Only that verified root hash and the previously declared
physical record fields could differ across layouts. Score, rank, identity and
all other semantic fields remained subject to comparison.

The [first fixed run remains failed](../graphify-fixture-failure-001/README.md).
Its twelve construction commands and 78 reads are still consumed. Across both
runs, actual totals are **60 constructions, 408 reads and 16 negative decisions**,
with 373.25 seconds of host runtime. This is no native speed ratio; the two designs
completed different scopes. The 2,096-file successful execution directory is
immutable and bound in the E8 evidence ledger.

The independent source review passed 45 new targeted probes and reused 41
unchanged source-bound branch cases. This observed full fixture pass now answers
the public artifact-correctness prerequisite for the exact builder. It does not
establish full-corpus feasibility, an EnterpriseRAG retrieval score, independent
acceptance or installation. The separately admitted native feasibility trial,
actual executor checks and final study review remain required.
