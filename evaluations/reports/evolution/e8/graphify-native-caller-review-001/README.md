## Remaining native boundary

E8's original controller remains active and unchanged. Before this fixed Graphify trial, all predecessor native work must settle, complete historical costs/exposures/unavailable profiles/counters must receive independent review, and the exact ordinary evaluation must be registered and design-sealed. A separate final admission is still required. The implementation receipt cannot substitute for any of those steps.

After admission, the single attempt is reserved before native Job creation. The planned order is run, generate/read the native report, and qualify while the admitted evaluation stage and ledger remain unchanged. Only then append evidence and close the stage. Any required failure preserves partial native artifacts and stops this fixed design; retries remain zero. A setup failure after reservation but before the launch exception handler can leave the consumed allocation without a separate caller-failure receipt; that diagnostic limit never permits a rerun.

The caller will observe actual Harbor-created containers at five checkpoints and bind the collected submission before verifier creation. Its copied skill is writable by container root, so pre/post hashes establish observed integrity rather than privileged immutability. Startup checks occur after container start. CPU and memory checks are planned, while Docker storage-quota enforcement is not claimed.
