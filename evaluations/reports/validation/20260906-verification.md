The report-only rehearsal used an isolated directory inside the ignored local
`tmp/` tree. It contained only the explicit aggregate source catalog, public
reports, generator and validator code, and skill entry-point documents. It
did not depend on the full EnterpriseRAG archive or any historical private
dataset. The 37 generated files matched the publication byte for byte.

The repository test command was:

```powershell
python scripts/check_coverage.py --threshold 80 --tests-args --basetemp tmp/enterprise-coverage-final
```

The test suite includes the new synthetic adapter, report catalog, and Git
index migration tests. Those cover deterministic selection, malformed archive
paths and symlinks, duplicate identities, evaluator separation, checksum drift,
metric units and missing data, ranking ties, table contracts, and preservation
of local files during removal from the Git index. Existing integration tests
ran with the local historical dataset copies still present.

## Storage and publication boundaries

The [migration receipt](../data-hygiene/20260906-index-migration.json) lists
aggregate counts by evaluation directory. The local payload files remain at
their original locations. The migration changes future Git snapshots and does
not remove content from earlier commits. Authored runtime definitions,
acquisition metadata, skill packages, and reviewed reports remain versioned.

Raw query-level results and logs remain local and ignored. The published hub
reads reviewed aggregates only. Historical source reports were not rescored;
each retains its own cohort, primary metric, runtime, and interpretation limits.

## Interpretation limits

This is a reference-enriched 40-question retrieval diagnostic from the pinned
Onyx source, with 985 documents from a 511,962-document archive. It is not an
execution of the full 500-question benchmark. Generated-answer correctness,
abstention, untouched validation, skill promotion, and local machine dollar
cost were not evaluated. Embeddings use deterministic 384-dimensional hashing.

Each route ran in a fresh process, with three repetitions and possible caches
within that route. P95 excludes initialization. Repository validation shared
the workstation during part of measurement, so latency is diagnostic and does
not support a controlled speed ranking.

CTA means cost, time, and accuracy/quality in this publication. Retrieval
quality remains separate from answer correctness. The general report preserves
ties, unavailable results, and the explicitly in-sample quantum error
correction comparison; it does not name a universal winner across datasets.
