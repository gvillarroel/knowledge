# ADR 0169: Check source-packed verifier conformance with fresh fixtures

Status: Accepted

Date: 2026-09-15

The [construction diagnostic](../../evaluations/reports/datasets/enterprise-build-profile-001/README.md) exposed a verifier assumption that logical record paths must be physical files. Its one-record-per-source rehearsal did not cover packed sources, and its four measured rewards remain failed.

Correct the verifier contract in a separate ordinary conformance exercise using fresh fictional sources. Derive logical paths from trusted identities, resolve physical files from trusted source multiplicity, require complete bodies and unique anchors, and retain the unchanged family validator as the complete positive gate. Keep skill source changes outside this treatment.

Exercise both single-record and multi-record sources for Entity Graph and Ensemble. Independently clone the positive artifacts for six explicit semantic corruptions. Count only the exact expected rejection before trusted validation; stop on any unexpected outcome and preserve unattempted checks. Freeze one family, four native originals, one attempt, no retries, one absolute verifier deadline and invocation caps before execution.

Pure preparation specimens and fake-evaluator controls do not prove complete native conformance. Record the native outcome separately after one-use admission. Publish aggregate observations by strategy, check and CTA; keep all fixtures, copied bundles, native artifacts and ledgers ignored.

This exercise supports the verifier contract only. It neither repairs previous rewards nor supplies missing retrieval scores or skill-promotion evidence. Future builder evolution still requires its own controller and fresh independent validation.
