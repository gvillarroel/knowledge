# ADR 0171: Close EnterpriseRAG with the accepted canonical skills

## Status

Accepted on 2026-09-18 at the user's request to close the campaign and push the
best supported skill versions.

## Context

G2's independently accepted generator delta is already canonical. Subsequent
maintenance preserved evidence checks and synchronized the eight embedded
builder/consultant pairs. Later EnterpriseRAG searches retained development
profiles, but their required joint acceptance did not complete. E15 and E16
have terminal outcomes. Separate public measurements added retrieval evidence
without authorizing promotion of those candidates.

## Decision

Retain the current generator and all sixteen matched canonical packages.
Verify their exact identities, the four promoted G2 files, and canonical/vendor
parity, then publish a release inventory. Preserve the distinction between G2's
historical accepted candidate digest and the subsequently maintained package.
Do not create a cosmetic skill mutation or install an experimental profile to
make this closure appear to contain a new accepted version.

Close the campaign at its existing terminal outcomes. Preserve failed and
incomplete measurements, unused hypotheses, and all original study evidence.
Do not restart native jobs, open private gates, rescore partial results, or
claim that all possible strategies were exhausted. Publish the closure and
update report discovery using the existing reviewed aggregates.

## Consequences

The repository retains the useful accepted generator behavior and tested
maintenance. Development-only profiles remain reproducible historical evidence,
with no claim of independent acceptance or automatic inheritance by generated
experts. The public retrieval catalog remains a descriptive comparison across
different runtime treatments, not an official answer-quality leaderboard.

The final gate checks package validity, vendored parity, generator behavior,
dataset descriptors, documentation links, application coverage and explicit
Git scope. The authorized push publishes this closure with the existing skill
bytes. Raw datasets and runtime artifacts remain ignored.
